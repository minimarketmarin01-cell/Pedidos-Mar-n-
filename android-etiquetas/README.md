# Etiquetas Marín 376 (app Android)

App para el POS con Android 8.1: elegir ensalada → cantidad → imprimir, por Bluetooth (impresora térmica de 58 mm).
Usa el mismo servidor que la app web (productos y códigos de barras) y dibuja la etiqueta como imagen (Code 128).

- Se compila sola en GitHub Actions (`.github/workflows/android-etiquetas.yml`).
- El APK queda en `descargas/etiquetas-marin376.apk` (se publica en la página de la app).
